# 果岭读线与洞位规划系统

浏览器内运行的果岭管理系统:地形建模、洞位规划、推杆模拟、赛事果岭图。数据全部保存在本机 localStorage,无需服务器。

## 技术栈

Vite + Vue 3 + TypeScript + three.js + Tailwind CSS 4

## 命令

```bash
pnpm install   # 安装依赖
pnpm dev       # 开发服务器
pnpm build     # 生产构建
pnpm test      # 物理与规划算法测试
```

## 功能

- **果岭档案**:18 洞管理,果岭速度(stimp)/湿度/草纹设置,CSV 测量点导入重建地形
- **地形编辑**:抬升/下压/平滑/整平笔刷,整体倾斜,等高线/坡度箭头/高度/坡度着色,2D/3D 预览
- **洞位规划**:点击放洞杯,自动检查 1m 内坡度与距边缘步数;一键生成 3 套 18 洞方案,前中后 × 左中右九宫格均衡,自动避开近期用过的位置
- **推杆模拟**:任意点推杆,轨迹实时计算,进洞/擦边/滑出判定;读线辅助给出贴洞/标准/强攻三档瞄准点与力度;三推风险热区
- **赛事果岭图**:规范出图,洞位距前沿/侧边步数标注,可打印
- **设置**:坡度上限、步长、进洞速度、复用告警等参数,洞位历史浏览

## 物理模型

- 摩擦系数由 stimp 定义反解:`mu = v0^2 / (2 * g * d)`,v0 = 1.8288 m/s(6 ft/s),平地停球距离与 stimp 读数严格一致(测试误差 < 0.5%)
- 固定步长(1/240 s)半隐式欧拉积分,零随机数:同起点同力度两次模拟轨迹逐点一致
- 坡度加速度 `-g * grad(h)`;露水增阻、干燥减阻;草纹各向异性(顺纹快逆纹慢)
- 洞杯捕获按碰撞参数(轨迹到杯心最近距离)计算有效进洞速度,超速则绕最近接近点确定性偏转(擦边/弹出)
